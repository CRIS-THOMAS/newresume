# Resume PDF Hosting

A simple, clean solution for hosting and displaying your resume PDF online using GitHub Pages.

## 🚀 Quick Start

1. **Replace the PDF**: Upload your resume PDF file and name it `resume.pdf` (replace the existing placeholder file)
2. **Enable GitHub Pages**: 
   - Go to your repository Settings
   - Navigate to "Pages" section
   - Under "Source", select the branch you want to deploy (e.g., `main` or `master`)
   - Click Save
3. **Access your resume**: Your resume will be available at `https://[your-username].github.io/[repository-name]/`

## 📁 Files

- `index.html` - The main page that displays your PDF
- `resume.pdf` - Your resume PDF file (replace this with your own)
- `.nojekyll` - Tells GitHub Pages not to use Jekyll processing

## ✨ Features

- **Clean, responsive design** - Works on desktop and mobile devices
- **PDF viewer** - View the PDF directly in the browser
- **Download button** - Easy one-click download option
- **Simple to use** - Just replace the PDF file and deploy

## 🔧 Customization

You can customize the `index.html` file to:
- Change the page title
- Modify colors and styling
- Add your name or additional information
- Adjust the layout

## 📝 Note

Make sure your PDF file is named `resume.pdf` or update the filename in `index.html` if you use a different name.
